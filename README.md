# \# cocotb ALU

# 

# A 4-bit ALU with 4 operations, verified with cocotb and Icarus Verilog.

# 

# \## Operations

# \- op = 00: add

# \- op = 01: subtract

# \- op = 10: AND

# \- op = 11: OR

# 

# \## Files

# \- alu.v: the Verilog design

# \- test\_alu.py: cocotb tests (one test for each operation)

# \- Makefile: runs the simulation

# 

# \## How to run

# make

# 

# \## Result

# TESTS=4 PASS=4 FAIL=0

#
